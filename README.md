# Лабораторная работа №3: Автоматизация модульного тестирования

Проект демонстрирует принципы модульного тестирования на Python с использованием
фреймворка **pytest** и оценки покрытия кода через **pytest-cov**.

## Цель работы

Освоить принципы модульного тестирования, научиться создавать автоматизированные
тесты на Python с использованием `pytest` и оценивать покрытие кода тестами.

## Структура проекта
- calculator.py # Модуль «Калькулятор комиссий»
- test_calculator.py # Модульные тесты
- requirements.txt # Зависимости проекта
- README.md # Документация
